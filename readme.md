# Glass Sounds

Replacement sounds for glass - softer walking sounds with 6 variations, instead of the previous 1 walking sound, and new breaking sounds.

All sounds were sourced from cc0 sources, but see credits.txt for links to originals.

## How to use

Simply enable the mod. It overrides the glass sounds from `default` or `mcl_sounds` - no other setup needed.

## Supported games

Works with `default` from `minetest_game`, and `mcl_sounds`-based games such as `Mineclonia` and `VoxeLibre`/`MineClone2`

## Custom nodes

For your own glass nodes, use `glass_sounds.node_sound_glass_defaults(tbl)` to get the same sounds instead of relying on the filename override.
